# Rubric — line-genre review (hidden from the reviewer)

Answer key per snippet. This file is the human grading key; never sent to the
reviewer. The comparison that matters is **B vs C on question 1's
classification** — that decides whether the genre clause earns landing.

## Snippet A (baseline: minimal overview + bare injection block)

Expected findings — the failure baseline:

1. **Nothing settles the genre.** No sentence defines the `[cognition-link]`
   lines or addresses them to the reader. A guess like "maybe docs for me" is
   acceptable only without a quote.
2. **No support for in-flow meaning.** A new line's appearance implies
   nothing quotable.

**Instrument-calibration read:** confident quoted answers on A mean the
questions are leading — recalibrate before trusting B/C. A is the negative
control for the instrument itself.

## Snippet B (treatment: same + the cognition-link directive)

1. The obligation sentence partially settles it — quotable: "When a
   [cognition-link] line names a path you are about to read or edit, read the
   linked cognition document before acting on that source file". **But nothing
   states the lines are not background metadata.** Expect wavering: some
   reviewers classify as addressed-to-them via the obligation; others read the
   obligation as applying to "a path I'm editing anyway" and still file the
   lines as tooling background. **Record the distribution — this is the
   comparison of interest.**
2. The deviation clause ("if you skip it, say why in one line") supports
   "there is a choice with accounting"; in-flow meaning is derivable only
   through the same obligation sentence.

## Snippet C (candidate: same + the genre clause)

1. Quotable genre sentence: "Treat [cognition-link] lines as pointers
   addressed to you, not as background metadata." Classification should be
   consistent (addressed-to-me) WITH the quote.
2. Same as B for in-flow meaning; the genre clause may make reviewers treat a
   newly appearing line as relevant to them by default.

## Landing rule (pre-registered)

- **Land the clause** iff C reviewers classify consistently (with quotes)
   while B reviewers waver or classify as background — i.e., the clause closes
   a real gap.
- **Do NOT land** if B already classifies consistently with quotes (the clause
   adds length without gain), or if C reviewers read the clause as a new
   obligation / hard rule (escalation — the clause must stay interpretive).

## Red flags worth recording (not failures)

- Reviewer reads C's clause as permission to ignore non-mentioned files (it is
  about genre, not scope).
- Reviewer conflates the genre clause with the deviation clause ("say why")
  — genre got mixed into obligation accounting.
- Reviewer answers B with quotes that only exist in C (snippet bleed —
  recalibrate the instrument).
